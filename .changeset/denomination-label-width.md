`DenominationGrid` takes a `labelWidth` (`docs/requests/teisoro-denomination-grid.md`, 2026-09-30 follow-up, Teisoro F-007-S05 task 1375, DRW-27). `labelWidth?: number` is the strip's row-label column width in characters of the label type (`ch`), an integer from 1 to 40 (anything else throws a `RangeError`). With it the strip takes the new generated class `sw-denomination-strip-aligned`: each count column keeps one token width (48 px, 24 px below `md`) and the strip is only as wide as its columns, so a row's total sits right after its counts and the spare width stays empty after the last column. Strips with the same columns and `labelWidth`, such as one per card in a feed, line their count columns up when their containers fit every column; in a narrower container the label column gives way, wrapping beside its icon, and they still line up while no total shows (below `md`) and each label's longest word fits. A visible total in a container too narrow, a strip that must scroll, a word longer than `labelWidth` or a count wider than its column can shift them, as the README details. The tiles layout ignores it. Without `labelWidth` nothing changes. No new dependencies.
