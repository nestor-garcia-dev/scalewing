`Table` `layout` and `verticalAlign`, and `TableCell` `width` (`docs/requests/teisoro-table.md`, 2026-10-08 follow-up, Teisoro F-006-S11, CHG-15 and HIS-12). `layout?: 'auto' | 'fixed'` (default `auto`): `fixed` sizes the columns from the header row's widths alone (`table-layout: fixed`), so a filter that hides a row moves no column; a column without a width shares what is left (when every column has one, spare width is shared in proportion to them). `width?: 'min' | 'xs' | 'sm' | 'md' | 'lg' | 'xl'` on a cell: the sizes are 4, 6, 8, 12 and 16 rem; `min` gives an auto table's column the least room its content allows and keeps that cell on one line (set it on each cell of the column), and is no width in a fixed table. `verticalAlign?: 'middle' | 'top'` (default `middle`): `top` starts every cell of a tall row on its first line. The deprecated HTML `width` attribute is no longer accepted on `TableCell`: browsers honoured it as a presentational hint, so a cell given `width="120"` had that width, and it is now a type error and a `RangeError`. Migration: pass one of the sizes above (`width="sm"` and so on), or a class of your own; no known consumer passed it. An unknown value throws a `RangeError`. New exported types `TableLayout`, `TableVerticalAlign`, `TableColumnWidth`; new generated classes `sw-table-fixed`, `sw-table-top`, `sw-table-col-{min,xs,sm,md,lg,xl}`. `TableCell` moved to its own module; its import path from the package is unchanged. No new tokens and no new dependencies.
