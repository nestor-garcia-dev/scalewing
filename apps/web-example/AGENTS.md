# Web example agent rules

Follow the root `AGENTS.md`. On conflict, the root wins.

## Hard rules

1. This app demonstrates public `@scalewing/react` exports. It is not a source of tokens.
2. Import `@scalewing/react/styles.css` once at the entry. Do not copy Scalewing CSS into `src`.
3. Use `sw-*` classes and components as a real consumer would.
4. Do not add product domain screens here.
