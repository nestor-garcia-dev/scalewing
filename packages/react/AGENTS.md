# React DOM agent rules

Follow the root `AGENTS.md`. On conflict, the root wins.

## Hard rules for React

1. This package renders to the DOM. Do not import `react-native`, Expo, or `@scalewing/react-native`.
2. Components stay thin. Visual values come from `@scalewing/tokens` or generated classes. The generators, class catalog, class-name helpers, and breakpoint token live in `src/css` (ADR 0010).
3. Consumers must import `@scalewing/react/styles.css` explicitly. Do not inject the stylesheet as a hidden side effect of component imports.
4. React is a peer dependency.
5. Prefer semantic HTML (`section`, `p`, headings, `button`, `a`, `label`) and preserve refs.
6. Public class names stay in the generated `sw-*` catalog.
7. Add tests for class mapping, theme switching, and accessibility of composed examples.
8. `Box hideBelow`/`hideFrom` toggle a region at the `md` or `lg` breakpoint token with generated `sw-hide-*` classes (`lg`, 64rem, is for visibility only; the layout props keep `md`), and `breakpointQuery` gives script the same query; products must not write their own media queries. `Grid` is equal-width columns from a bounded count, with `align` reusing the `sw-align-*` classes of `Stack` and `Inline`; a direct child's `columnSpan` (any Box-based component) covers several columns and is capped at the grid's count at the current width by generated `sw-grid-span-*` rules. `Box as="a"` is a layout link. Do not add `as="button"`; use `Button`. Button `variant="neutral"` (web only) is a quiet grey fill; `disabledAppearance="neutral"` greys a disabled button instead of fading it; both opt-in. `Box border` is a token hairline from the generated `sw-border` classes, solid or `'dashed'` for a space filled in by hand. Field wraps a native control with token gap; `requiredMark="hidden"` (opt-in, also on Select, DateField, Combobox and FilterChips) drops the label's visual asterisk while the control stays required; `prefix`/`suffix` put short text such as a unit inside one native input's frame, outside its value; a press on the frame focuses the input. DateField is a typed date-only text entry in the locale's order plus its own calendar dialog on the popover layer (WAI-ARIA date picker dialog pattern); it does not use the browser's date input, and its own words come from `labels`, never hard-coded product copy. CalendarButton is an icon-only Button that opens that same calendar for a date the page already shows (a day heading with its own previous and next steps); its name is `label` plus the spoken date, it never holds an empty value, and a coarse pointer gets the 44 px md target at every size. Do not make a date's text itself the trigger. InfoTip is a toggletip: an icon-only ghost Button whose only job is to show its tip, built on Tooltip's anchor (the internal `pressToggles` option, not a Tooltip prop); a press opens it and also says it in a polite live region. A Tooltip on a Button that acts never opens on a tap; do not make a non-control focusable to get one. Select is a labeled listbox menu; Field remains the native OS picker. `size="xs"` and `labelVisuallyHidden` are for toolbar chrome; `width="full"` fills a form or phone column instead of sizing to the longest option. `action` is a last listbox command that does not become the value. Combobox is typing with suggestions the consumer filters (groups, badges, a disabled option, an action), never a Select with search. MultiSelect is several choices: a disclosure button showing a group of native checkboxes (with All and Clear) on the popover layer, not a listbox. Native text controls inherit the generated document canvas, including accent focus; do not restyle them with hex in JSX. A programmatic focus target (`tabindex="-1"`) takes the canvas's accent ring at zero specificity, so a component's own ring wins. Badge is not a button; `size="sm"` is the table chicklet. SegmentedControl is one exclusive choice; an item `icon` is a hidden mark before its label, and a compact track with icons is md height on a subtle fill (a filled or raised one only gains the marks); `variant="raised"` (opt-in) is a grey track with a raised white selection. Table `density="compact"` and `TableRow selected` are for ranked lists. A ledger takes `Table columnRules`, `TableCell tone` and `TableRow variant="sub"` / `struck` (a voided row says why in a Badge in the title's line). `TableFooter` holds a total; `sticky` pins it to the page's bottom edge while the table fits its width (never paired with a sticky ActionBar or a Dialog footer, which cover it). BarChart is a labeled horizontal magnitude chart. Split is a start pane with a drag separator, a max width, and collapse below min. Accordion is a native `<details>` disclosure in page flow with a generated chevron in place of the browser triangle; `subtitle` is one muted line under the title and `size="sm"` is a nested disclosure with an `sm` control header. Dialog is a modal `<dialog>` on the top layer; `sheetBelow` docks it as a bottom sheet below the breakpoint, and `closeLabel` adds its own icon-only close button with a private CSS glyph (no icon dependency); `icon` and `description` fill the header, `footer` (with ActionBar's `summary` in a polite status) is pinned to its bottom edge, `size="xl"` is 65rem and `role="alertdialog"` marks a warning that interrupts. `appearance="banded"` (opt-in) is the solid sheet with its title row and footer as hairline-ruled bands and a round close button. GlyphTile is a decorative categorical-colour square holding a white consumer glyph (a direct-child SVG is drawn at spacing step 4, the first slot that sizes its glyph) (the hues come from tokens; the consumer maps kinds to hues). Notice is a tinted note in the page's flow (info, success, warning, danger) that stays until the page removes it; its fill and ink come from the semantic colors, and danger is an alert; `variant="band"` is a full-width strip of page chrome (an environment strip) with no live region by default. Toast is an auto-dismiss status on the popover layer; it does not trap focus. `anchor` and `target` send it from a press to a destination; `placement="top-end"` with `title`, `action` and `showRemaining` makes it a corner card whose time holds on hover or focus. AppHeader is sticky glass chrome. `Tabs sticky` holds a page's section strip at the top as a band of the canvas on the AppHeader's layer, not a second header or a glass card. ActionMenu `triggerAppearance="text"` (opt-in) is an unframed trigger: its words and a chevron. ActionBar is a long page's actions and one polite live status line (optionally led by a `summary` figure: label, large tabular value, detail) on a glass bar stuck to the viewport bottom (optionally only below `md`), clearing the safe area; it is not a toolbar or a second header. Every generated `z-index` is a layer of `src/css/stacking.ts`; an open popup paints over the ActionBar. Stepper is a whole-number count between − and + (one spin button tab stop); `limitAppearance="plain"` keeps a button at its limit unfaded (still disabled). DenominationGrid entry rows are a strip's Steppers; `labelAppearance="plain"` drops the row labels' tone stripe; `frame="table"`, `totalEmphasis="strong"`, `cellToneAppearance="pill"` and an empty `zeroLabel` are the opt-in framed count-sheet look (a frame on the scroll region, bold totals, a toned count on its tone's tint, blank zeros), off by default. Steps is a one-page vertical stepper; a Step only lives in a Steps list. Nav is a label-size link cluster; a `Button` in it is a 44 px target on a coarse pointer; `appearance="words"` (opt-in) draws its destinations as plain words, the current one bold in the text color. SectionNav is the quieter navigation between one area's sections: links with `aria-current`, a row marked by an underline or, from `verticalFrom`, a side list marked by a bar; `onNavigate` takes a plain press for a client router. An item's `count` is a pill read in its name; `appearance="filled"` is the quiet button row beside an area's name. ThemeProvider `palette` applies a named token overlay; do not invent hex in JSX to retint the canvas. Public names stay generic so every product can reuse them.
9. A new or changed public web token, class, variant, or component is not done until `apps/gallery` demonstrates the meaningful states.

## Prefer

```ts
<Box as="a" href="#layout" padding={4} paddingTop={2}>
  {children}
</Box>
```

which maps to `sw-padding-4 sw-padding-top-2`.

## Avoid

Hex colors in JSX, copied CSS in examples, and React Native primitives.
