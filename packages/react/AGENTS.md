# React DOM agent rules

Follow the root `AGENTS.md`. On conflict, the root wins.

## Hard rules for React

1. This package renders to the DOM. Do not import `react-native`, Expo, or `@scalewing/react-native`.
2. Components stay thin. Visual values come from `@scalewing/tokens` or generated classes. The generators, class catalog, class-name helpers, and breakpoint token live in `src/css` (ADR 0010).
3. Consumers must import `@scalewing/react/styles.css` explicitly. Do not inject the stylesheet as a hidden side effect of component imports.
4. React is a peer dependency. The runtime dependencies are `@scalewing/tokens`, `pdfjs-dist` (DocumentViewer) and `markdown-it` (MarkdownView), as the root `AGENTS.md` lists them.
5. Prefer semantic HTML (`section`, `p`, headings, `button`, `a`, `label`) and preserve refs.
6. Public class names stay in the generated `sw-*` catalog.
7. Add tests for class mapping, theme switching, and accessibility of composed examples.
8. `Box hideBelow`/`hideFrom` toggle a region at the `md` or `lg` breakpoint token with generated `sw-hide-*` classes (`lg`, 64rem, is for visibility only; the layout props keep `md`), and `breakpointQuery` gives script the same query; products must not write their own media queries. `Grid` is equal-width columns from a bounded count, with `align` reusing the `sw-align-*` classes of `Stack` and `Inline`; a direct child's `columnSpan` (any Box-based component) covers several columns and is capped at the grid's count at the current width by generated `sw-grid-span-*` rules. `Box as="a"` is a layout link; `link="quiet"` (opt-in, `as="a"` only) is a row title's link in the surrounding text's colour, set apart by weight 600, never by colour alone. Do not add `as="button"`; use `Button`. Button `variant="neutral"` (web only) is a quiet grey fill; `disabledAppearance="neutral"` greys a disabled button instead of fading it; both opt-in. Button `width="full"` (opt-in) fills its column, or in an Inline row the space its siblings leave. A Button with `aria-disabled="true"` looks disabled (either appearance) but stays focusable and its `onPress` runs: the consumer decides what a press while off does. `Box border` is a token hairline from the generated `sw-border` classes, solid or `'dashed'` for a space filled in by hand, or `'bottom'` (opt-in) for a hairline under a full-width bar only. Field wraps a native control with token gap; `requiredMark="hidden"` (opt-in, also on Select, DateField, Combobox and FilterChips) drops the label's visual asterisk while the control stays required; `prefix`/`suffix` put short text such as a unit inside one native input's frame, outside its value; a press on the frame focuses the input. `width` (opt-in, the Table column sizes `xs`–`xl`) caps only the control (or its adorned or search frame) at the column's start, never past the column; the label and messages keep the column. DateField is a typed date-only text entry in the locale's order plus its own calendar dialog on the popover layer (WAI-ARIA date picker dialog pattern); it does not use the browser's date input, and its own words come from `labels`, never hard-coded product copy; `entry="calendar"` (opt-in) replaces the text entry with one neutral field-shaped Button showing the day (or `labels.chooseDate`) that opens the same calendar, named by the label and its words, `labels.required` said after it while required. CalendarButton is an icon-only Button that opens that same calendar for a date the page already shows (a day heading with its own previous and next steps); its name is `label` plus the spoken date, it never holds an empty value, and a coarse pointer gets the 44 px md target at every size. Do not make a date's text itself the trigger. DateRangeButton is a Button showing a range (`{ start, end }`) that opens a calendar on the same private grid, popover and month steps to pick a first and a last day: from `md` a popover with `presets` (a press applies one at once) beside two months (above them below `lg`), below `md` a Dialog bottom sheet with one month; Apply gives the range, Cancel, Escape and a press outside keep it; `maxDays` disables the days past that length from a pressed start; the range being picked is a polite status and its name is `label` plus the range it shows. An attached ButtonGroup finds its buttons by type, so an open calendar beside one does not break its dividers or corners. InfoTip is a toggletip: an icon-only ghost Button whose only job is to show its tip, built on Tooltip's anchor (the internal `pressToggles` option, not a Tooltip prop); a press opens it and also says it in a polite live region. A Tooltip on a Button that acts never opens on a tap; do not make a non-control focusable to get one. Select is a labeled listbox menu; Field remains the native OS picker. `size="xs"` and `labelVisuallyHidden` are for toolbar chrome; `width="full"` fills a form or phone column instead of sizing to the longest option. `aria-labelledby` (opt-in, in place of `label`) names a Select by words the page already draws, and it then draws no label of its own, so the name is read once. `action` is a last listbox command that does not become the value. Combobox is typing with suggestions the consumer filters (groups, badges, a disabled option, an action), never a Select with search. MultiSelect is several choices: a disclosure button showing a group of native checkboxes (with All and Clear) on the popover layer, not a listbox. FilterChips is a labelled row of chips (native radios, or checkboxes with `multiple`, each its own Tab stop and never `required`); `labelVisuallyHidden`, `countAppearance="inline"` ("Open · 3", the dot hidden) and `overflow="scroll"` (one row scrolling inside its own box, never the page) are opt-in; an option's `tone="warning"` (opt-in) is the warning tint and ink (`toneTintFill`/`toneTintInk`, a warning Notice's) while the chip is not chosen, its words saying why. FilterChipsRow lays several FilterChips groups on one row (each keeping its own name and choices), an `end` group at the row's end; with `overflow="scroll"` the row is the one box that scrolls sideways, positioned so a group's hidden legend stays inside it, and the groups' own scroll gives way. FileField is one file chosen with the system picker (a hidden native input opened by its own button, never a Tab stop) or dropped on its frame; it has Field's label, description and error, hands the `File` to `onChange`, shows the consumer's `value` (name and detail, and a decorative thumbnail from `value.preview`, an image address the consumer makes) with a change button (and Remove with `onRemove` and `removeLabel`, opt-in), at a text field's height with `compact` (opt-in: the thumbnail and cut name are the change button), and never reads or uploads the file. Article reuses Card's classes (`sw-card`, `sw-card-<variant>`) on an `article` named by its title (a `Text` heading, `h1` to `h3`); its width is the `--sw-reading-max` variable, and its cover takes the card's top corners with `inherit`, never `overflow: hidden`, so a popup in its actions is not clipped. `contentLang` (opt-in) is `lang` on the title's heading and the body's box only, never the eyebrow, meta, actions or cover. MarkdownView parses Markdown to tokens with `markdown-it` (never its HTML renderer) and draws a safe subset as React elements, never `dangerouslySetInnerHTML`; a link's address passes `safeLinkHref` (http, https, mailto) or is dropped to its words, and the only image is a `photo:` id the consumer resolves to a safe address; the readers name every token they draw, and any other token is at most its words; the parser's nesting is capped (`markdown-limits.ts`) so no input overflows the stack, and its work is linear; add any slow shape found to the crafted-input tests. Native text controls inherit the generated document canvas, including accent focus; do not restyle them with hex in JSX. `sw-container-reading` (a utility, opt-in) is `sw-container` at the reading width (`--sw-reading-max`). `sw-font-mono` (a utility, opt-in) sets an element or a text control in the generic monospace families (`ui-monospace, monospace`); name no face there, a face would be a token. A programmatic focus target (`tabindex="-1"`) takes the canvas's accent ring at zero specificity, so a component's own ring wins. An attached ButtonGroup with `appearance="track"` (opt-in) is one grey track of words with hairline dividers. Badge is not a button; `size="sm"` is the table chicklet. SegmentedControl is one exclusive choice; an item `icon` is a hidden mark before its label, and a compact track with icons is md height on a subtle fill (a filled or raised one only gains the marks); `variant="raised"` (opt-in) is a grey track with a raised white selection; `fullWidthBelow="md"` (opt-in, here and on an attached ButtonGroup) fills the column on a phone with equal segments or buttons, and `size="sm"` keeps every segment's label on one line. Table `density="compact"` and `TableRow selected` are for ranked lists. `TableRow pressable` (opt-in) makes a whole row the pointer target of its one action, its first link or button (a `TableCell onPress` draws a cell's text as that button at weight 600); the row stays a non-control, so keyboard and assistive technology use the action itself, and presses with a modifier, on another control or ending a text selection are left alone. A ledger takes `Table columnRules`, `TableCell tone` and `TableRow variant="sub"` / `variant="total"` (a bold subtotal mid-table under the footer's 2 px rule, no fill) / `struck` (a voided row says why in a Badge in the title's line). A sticky `Table` header pins the whole `TableHeader` as one group (the `thead`), every row and cell in it, `td` as well as `th`. `Table stickyHeader="page"` (opt-in) pins the header to the page's top while the table fits its width, with no sticky footer. `TableFooter` holds a total; `sticky` pins it to the page's bottom edge while the table fits its width (never paired with a sticky ActionBar or a Dialog footer, which cover it). `Table maxHeight` (opt-in, `{ rows }`) bounds a table to a row count of its own region, where the rows scroll with the header pinned to the region's top and a sticky footer to its bottom, the shade cast from the pinned row; it never pins to the page and needs `stickyHeader` true. ListGroup is the web twin of native's: a `ul` (role kept) of ListRows with hairlines between them, a `panel` or `plain` rows in a Card, or `tiles` (opt-in: the same list, each row its own panel in `tileColumns` 2–4 equal columns from md, one a row below it, never bounded or with a footer); `maxHeight` (`{ rows }` of a title and one detail line) scrolls the rows in the shared named scroll region with top and bottom shades, and `footer` is pinned under it outside the list (a ListRow there is a `div`). A ListRow with `onPress` or `href` is the whole button or link (named by title and value, described by its details, a chevron, an inset ring, 44 px on a coarse pointer); `selected` is a choice with a check; without either it is a statement; `leading` is a hidden consumer mark; `valueTone="warning"` is the warning ink (the warning colour halfway to the text colour, 4.5:1 on the surface in every palette) and `valueBadge` draws the value as a Badge, never both. `unread` (with a required `unreadLabel`, read after the title) is an accent dot after the title; `tag` is a status (a Badge) before the row's end that describes it; `action` is a control after the row, its sibling in the list item and outside its press area (`ListRowItem`), the hover fill spanning both. `truncate` (opt-in) keeps the title and detail to one line each with an ellipsis, the title's words in their own box (`sw-list-row-title-text`) so the dot is never cut, the whole words still in the name, description and a `title` tooltip. `titleLang` (opt-in) is `lang` on the title's box only (its words and the wordless dot), never the detail, value, tag or unread words. BarChart is a labeled horizontal magnitude chart; an item `tone="neutral"` is the muted grey and `appearance="bare"` (opt-in) drops the track and the axis. DataBar is a decorative (`aria-hidden`) range bar for a table cell or list row, `from` to `to` on a `min` to `max` domain with a zero line when it spans zero; its tones (`neutral`, `success`, `muted`, `strong`, `accent`, `danger`) are semantic colours mixed into the surface; money out is `muted`, never danger, and `danger` is for a shortage only. ChartLegend is a chart's key: a list (`role="list"` kept) of items, each an `aria-hidden` swatch (`bar`, `line`, `marker`, `box`) and its words; a swatch reads its colour from a shared tone class (`sw-chart-tone-<tone>`, `src/css/chart-tones.ts`) whose custom properties (`--sw-chart-fill`, `--sw-chart-stroke`, `--sw-chart-ink`) every chart mark reads too, so a swatch is always the colour of the mark it names; a `bar` takes a fill tone (the categorical colours, DataBar's statement tones), the others a stroke tone (`accent`, `success`, `warning`, `danger`, `neutral`). DataBar's fills come from the same table. ColumnChart is columns per category (`stacked`, positives up and negatives down from zero, or `grouped`), series in categorical hues, an optional accent line on its own right-hand scale (zero and grid lines level with the columns', its last value beside that axis), a boxed `highlight` and `callouts` pinned above a column with a leader. It is an SVG laid out in its own pixels for the width it measures (`useChartWidth`; pure layout in `src/column-chart-*.ts`, scale and axis helpers shared with later charts in `src/chart-scale.ts`, `src/chart-axis.ts`, `src/chart-metrics.ts`); under `chartCompactWidth` it is shorter, labels fewer categories (always the last) and lists its callouts under the plot, never scrolling sideways. The drawing is `aria-hidden`; a table captioned by `label` in a `sw-sr-only` box (private `ChartTable`; a table is never narrower than its contents, so the box is what is hidden) carries every figure, the boxed row `aria-current`, and the callouts stay a list. LineChart is a value by date (`YYYY-MM-DD` points in date order, placed by days between them): `linear` or `step` (a value held until the next date), an optional `area` tint of its stroke tone, `markers` (a downward triangle and words on one of its points' dates, words dropped where they would meet), a boxed `highlight` period, labelled `ticks` (thinned from the last) and its last value beside the plot. It shares ColumnChart's measuring, scale, value axis, hidden table and plot CSS (`src/line-chart-*.ts`, `src/chart-dates.ts`, `css-line-chart.ts` for its area and markers). DocumentViewer draws a PDF from bytes (never a URL) a page at a time with PDF.js: all PDF.js use is in `components/document-viewer/pdf-document.ts` (a dynamic import of the legacy build, so a page without a viewer never loads it) with the hardened options in `pdf-options.ts` (nothing fetched beyond the bytes, no eval, no XFA); its worker is the `./document-viewer-worker` export, the same pinned version; the page's text is PDF.js's transparent text layer, styled by generated rules; 48-point steps reuse the pager's chevron; zoom is a pure clamp (`zoom.ts`) applied by a pinch and the keys. Pagination is a labelled `nav` holding the consumer's `rangeLabel` (a polite live region) and previous and next icon-only neutral Buttons named by `labels`; at an end a step is `aria-disabled`, never `disabled`, so it stays a Tab stop and focus is not dropped, and its press does nothing. Split is a start pane with a drag separator, a max width, and collapse below min. Accordion is a native `<details>` disclosure in page flow with a generated chevron in place of the browser triangle; `subtitle` is one muted line under the title and `size="sm"` is a nested disclosure with an `sm` control header. Dialog is a modal `<dialog>` on the top layer; `sheetBelow` docks it as a bottom sheet below the breakpoint, and `closeLabel` adds its own icon-only close button with a private CSS glyph (no icon dependency); `icon` and `description` fill the header, `footer` (with ActionBar's `summary` in a polite status) is pinned to its bottom edge, `size="xl"` is 65rem and `role="alertdialog"` marks a warning that interrupts. `status` adds a line beside the actions in that live region, `canvas="grouped"` (opt-in) fills it with the grouped canvas so cards stand apart, and `sheetGrabber` (needs `sheetBelow`) draws a decorative grabber on the bottom sheet only; a summary with an empty value draws no figure until it has one. `appearance="banded"` (opt-in) is the solid sheet with its title row and footer as hairline-ruled bands and a round close button. StatTile is one figure with its label; `appearance="plain"` (opt-in) drops its surface, edge and padding for figures inside a card (never with `emphasis="primary"`), divided by a Separator the consumer composes. GlyphTile is a decorative categorical-colour square holding a white consumer glyph (a direct-child SVG is drawn at spacing step 4, the first slot that sizes its glyph) (the hues come from tokens; the consumer maps kinds to hues). Notice is a tinted note in the page's flow (info, success, warning, danger) that stays until the page removes it; its fill and ink come from the semantic colors, and danger is an alert; `variant="band"` is a full-width strip of page chrome (an environment strip) with no live region by default. Toast is an auto-dismiss status on the popover layer; it does not trap focus. `anchor` and `target` send it from a press to a destination; `placement="top-end"` with `title`, `action` and `showRemaining` makes it a corner card whose time holds on hover or focus. AppHeader is sticky glass chrome; `appearance="bar"` (opt-in) makes it a full-width band of the solid surface with a hairline under it and no rounding. `Tabs sticky` holds a page's section strip at the top as a band of the canvas on the AppHeader's layer, not a second header or a glass card. ActionMenu `triggerAppearance="text"` (opt-in) is an unframed trigger: its words and a chevron. `triggerAppearance="icon"` (opt-in) is the consumer's glyph alone in a round quiet button, no chevron, named by `label`, and needs a glyph. ActionBar is a long page's actions and one polite live status line (optionally led by a `summary` figure: label, large tabular value, detail) on a glass bar stuck to the viewport bottom (optionally only below `md`), clearing the safe area; it is not a toolbar or a second header. Every generated `z-index` is a layer of `src/css/stacking.ts`; an open popup paints over the ActionBar. Stepper is a whole-number count between − and + (one spin button tab stop); `limitAppearance="plain"` keeps a button at its limit unfaded (still disabled). Switch `layout="trailing"` (opt-in) is a full-width row with the control after its words; `checkedTone="success"` (opt-in) is the success track while on. DenominationGrid entry rows are a strip's Steppers; a row's `valueRow` (opt-in, strip only) is a value line under it on the subtle fill, consumer-formatted values centred under the counts and the row's total moved onto it, each entry count described by its value; `labelAppearance="plain"` drops the row labels' tone stripe; `frame="table"`, `totalEmphasis="strong"`, `cellToneAppearance="pill"` and an empty `zeroLabel` are the opt-in framed count-sheet look (a frame on the scroll region, bold totals, a toned count on its tone's tint, blank zeros), off by default. A row's `negativeAppearance="plain"` keeps money going out out of red; `transposeBelow` draws a strip with the denominations as rows below `md`/`lg` (`TransposedStrip`, the same cells); `countDigits` widens entry counts. Steps is a one-page vertical stepper; a Step only lives in a Steps list; a folded step's heading is read as one hidden line, title, comma and status word, its drawn title `aria-hidden` on its own box (never a wrapper, which Chrome would read through an `aria-labelledby` reference); `Steps open` (opt-in) keeps every step open as a region named by its title, its marker alone following the status, nothing `aria-current` and no focus moved. A Step's `titleDetail` (opt-in) is muted words beside an open step's title in a wrapping title line (`css-steps-title-detail.ts`), outside the heading, describing an open list's region. Nav is a label-size link cluster; a `Button` in it is a 44 px target on a coarse pointer; `appearance="words"` (opt-in) draws its destinations as plain words, the current one bold in the text color. `NavCount` is a count placed inside a destination after its words: SectionNav's count pill (one shared rule, `css-count-pill.ts`), read in the destination's name, `countLabel` in place of the bare number; `tone="accent"` (opt-in) is the accent pill for news rather than work waiting; `tone="warning"` (opt-in) is amber for work that needs the person but is not urgent: the warning tint and ink (a warning Notice's, 4.5:1 in every palette) inside a warning edge. SectionNav is the quieter navigation between one area's sections: links with `aria-current`, a row marked by an underline or, from `verticalFrom`, a side list marked by a bar; `onNavigate` takes a plain press for a client router. An item's `count` is a pill read in its name; `appearance="filled"` is the quiet button row beside an area's name. AppShell is a workspace's frame (`app-shell/`, `css-app-shell*.ts`): a sticky full-height sidebar of grouped destinations (each item SectionNav's rules, `nav-items.ts`, plus a required icon) beside `main`, which never becomes its own scroll box; from 75rem the full sidebar (an internal media query, `appShellWideQuery`, not a public breakpoint), from `lg` to 75rem a rail of glyphs whose labels stay in the name and show in a Tooltip (its `aria-describedby` dropped, the words already being the name) with `railHeader`/`railFooter`, and below `lg` an AppHeader `bar` whose icon-only menu Button opens the same header, nav and footer in a modal drawer from the inline start on the top layer (Dialog's `useDialogCloseRequests`; a plain press on a destination closes it without moving focus; a dismissal returns focus to the menu button; `header`/`footer` mount in both the sidebar and the open drawer, so slot content takes no fixed id; either may host an interactive trigger, whose popup is on the top layer). Its count is the shared pill (`sw-app-shell-count`), its item's `countTone` NavCount's tones; `menuCount` (opt-in) is the same pill on the menu button's corner, read in its name after a comma. `pageBar` (opt-in, `css-app-shell-page-bar.ts`) is a solid band with a hairline under it at the top of `main`, sticky on the top chrome's layer: at the top from `lg`, under the compact bar below it, whose height the shell measures into `--sw-app-shell-bar-height` (a CSS fallback before that). `navLabel` is a string because it names both navs and the drawer. ContextSwitcher (`context-switcher/`, `css-context-switcher*.ts`) is a button named by its `label` and what it shows that opens a non-modal `dialog` on the top layer (the menus' anchored popover): an optional filter field (an ARIA combobox filtering by label or detail, folded, empty words in a polite status), the options in groups as a listbox (`aria-activedescendant`, the current one `aria-selected` with the accent check, each option's mark, detail, Badge and shared count pill `sw-context-switcher-count` read in its name), and footer commands (ghost sm Buttons); choosing or a command returns focus to the trigger first; Escape is stopped at the popup so a drawer round it stays open; the pure filtering and typeahead are `context-switcher/options.ts`. Its `icon` appearance is a glyph alone named by the label and the current option. CommandPalette (`command-palette/`, `css-command-palette*.ts`) is a native modal `<dialog>` kept in step with `open` by `useDialogCloseRequests`, near the window's top: a field (an ARIA combobox, `aria-activedescendant`) over an always-open listbox of the consumer's filtered groups (the active row `aria-selected` with the hidden Enter key cap), a polite status (count, empty or loading words) and a hint; choosing calls `onOpenChange(false)` then `onSelect`; focus returns to the opener unless moved; `shortcut="mod+k"` is one document `keydown` listener (⌘ on Apple, Ctrl elsewhere, ignored in another text field; pure checks in `command-palette/shortcut.ts`). CommandPaletteTrigger is the search pill with the shared key cap (`sw-command-palette-key`) or a compact glyph. ThemeProvider `palette` applies a named token overlay; do not invent hex in JSX to retint the canvas. `ThemeProvider canvas="grouped"` (opt-in, `data-canvas`) is the page on a quiet grey under white cards (light: the background with 7 % muted; dark: the background), read from `--sw-canvas-grouped` by any surface that sits on it; links and accent words stay in the cards. Every press control and link renders an explicit `tabIndex` (`tabStop` in `src/tab-stop.ts`, a radio group's checked radio by `radioTabStopValue`), because Safari leaves buttons, links, checkboxes and radios out of the Tab order without one; a consumer's `tabIndex` wins and a deliberate `-1` (Stepper −/+, roving items) stays; every SegmentedControl item is a stop (its arrows change the value, not the focus). A new raw `<button>`, link or checkbox takes it too. Public names stay generic so every product can reuse them.
9. A new or changed public web token, class, variant, or component is not done until `apps/gallery` demonstrates the meaningful states.

## Prefer

```ts
<Box as="a" href="#layout" padding={4} paddingTop={2}>
  {children}
</Box>
```

which maps to `sw-padding-4 sw-padding-top-2`.

## Avoid

Hex colors in JSX, copied CSS in examples, and React Native primitives.
