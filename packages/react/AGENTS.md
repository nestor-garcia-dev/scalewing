# React DOM agent rules

Follow the root `AGENTS.md`. On conflict, the root wins.

## Hard rules for React

1. This package renders to the DOM. Do not import `react-native`, Expo, or `@scalewing/react-native`.
2. Components stay thin. Visual values come from `@scalewing/tokens` or generated classes. The generators, class catalog, class-name helpers, and breakpoint token live in `src/css` (ADR 0010).
3. Consumers must import `@scalewing/react/styles.css` explicitly. Do not inject the stylesheet as a hidden side effect of component imports.
4. React is a peer dependency.
5. Prefer semantic HTML (`section`, `p`, headings, `button`, `a`, `label`) and preserve refs.
6. Public class names stay in the generated `sw-*` catalog.
7. Add tests for class mapping, theme switching, and accessibility of composed examples.
8. `Box hideBelow`/`hideFrom` toggle a region at the `md` or `lg` breakpoint token with generated `sw-hide-*` classes (`lg`, 64rem, is for visibility only; the layout props keep `md`), and `breakpointQuery` gives script the same query; products must not write their own media queries. `Grid` is equal-width columns from a bounded count, with `align` reusing the `sw-align-*` classes of `Stack` and `Inline`; a direct child's `columnSpan` (any Box-based component) covers several columns and is capped at the grid's count at the current width by generated `sw-grid-span-*` rules. `Box as="a"` is a layout link; `link="quiet"` (opt-in, `as="a"` only) is a row title's link in the surrounding text's colour, set apart by weight 600, never by colour alone. Do not add `as="button"`; use `Button`. Button `variant="neutral"` (web only) is a quiet grey fill; `disabledAppearance="neutral"` greys a disabled button instead of fading it; both opt-in. A Button with `aria-disabled="true"` looks disabled (either appearance) but stays focusable and its `onPress` runs: the consumer decides what a press while off does. `Box border` is a token hairline from the generated `sw-border` classes, solid or `'dashed'` for a space filled in by hand, or `'bottom'` (opt-in) for a hairline under a full-width bar only. Field wraps a native control with token gap; `requiredMark="hidden"` (opt-in, also on Select, DateField, Combobox and FilterChips) drops the label's visual asterisk while the control stays required; `prefix`/`suffix` put short text such as a unit inside one native input's frame, outside its value; a press on the frame focuses the input. DateField is a typed date-only text entry in the locale's order plus its own calendar dialog on the popover layer (WAI-ARIA date picker dialog pattern); it does not use the browser's date input, and its own words come from `labels`, never hard-coded product copy. CalendarButton is an icon-only Button that opens that same calendar for a date the page already shows (a day heading with its own previous and next steps); its name is `label` plus the spoken date, it never holds an empty value, and a coarse pointer gets the 44 px md target at every size. Do not make a date's text itself the trigger. DateRangeButton is a Button showing a range (`{ start, end }`) that opens a calendar on the same private grid, popover and month steps to pick a first and a last day: from `md` a popover with `presets` (a press applies one at once) beside two months (above them below `lg`), below `md` a Dialog bottom sheet with one month; Apply gives the range, Cancel, Escape and a press outside keep it; `maxDays` disables the days past that length from a pressed start; the range being picked is a polite status and its name is `label` plus the range it shows. An attached ButtonGroup finds its buttons by type, so an open calendar beside one does not break its dividers or corners. InfoTip is a toggletip: an icon-only ghost Button whose only job is to show its tip, built on Tooltip's anchor (the internal `pressToggles` option, not a Tooltip prop); a press opens it and also says it in a polite live region. A Tooltip on a Button that acts never opens on a tap; do not make a non-control focusable to get one. Select is a labeled listbox menu; Field remains the native OS picker. `size="xs"` and `labelVisuallyHidden` are for toolbar chrome; `width="full"` fills a form or phone column instead of sizing to the longest option. `action` is a last listbox command that does not become the value. Combobox is typing with suggestions the consumer filters (groups, badges, a disabled option, an action), never a Select with search. MultiSelect is several choices: a disclosure button showing a group of native checkboxes (with All and Clear) on the popover layer, not a listbox. Native text controls inherit the generated document canvas, including accent focus; do not restyle them with hex in JSX. A programmatic focus target (`tabindex="-1"`) takes the canvas's accent ring at zero specificity, so a component's own ring wins. An attached ButtonGroup with `appearance="track"` (opt-in) is one grey track of words with hairline dividers. Badge is not a button; `size="sm"` is the table chicklet. SegmentedControl is one exclusive choice; an item `icon` is a hidden mark before its label, and a compact track with icons is md height on a subtle fill (a filled or raised one only gains the marks); `variant="raised"` (opt-in) is a grey track with a raised white selection. Table `density="compact"` and `TableRow selected` are for ranked lists. `TableRow pressable` (opt-in) makes a whole row the pointer target of its one action, its first link or button (a `TableCell onPress` draws a cell's text as that button at weight 600); the row stays a non-control, so keyboard and assistive technology use the action itself, and presses with a modifier, on another control or ending a text selection are left alone. A ledger takes `Table columnRules`, `TableCell tone` and `TableRow variant="sub"` / `variant="total"` (a bold subtotal mid-table under the footer's 2 px rule, no fill) / `struck` (a voided row says why in a Badge in the title's line). A sticky `Table` header pins the whole `TableHeader` as one group (the `thead`), every row and cell in it, `td` as well as `th`. `Table stickyHeader="page"` (opt-in) pins the header to the page's top while the table fits its width, with no sticky footer. `TableFooter` holds a total; `sticky` pins it to the page's bottom edge while the table fits its width (never paired with a sticky ActionBar or a Dialog footer, which cover it). `Table maxHeight` (opt-in, `{ rows }`) bounds a table to a row count of its own region, where the rows scroll with the header pinned to the region's top and a sticky footer to its bottom, the shade cast from the pinned row; it never pins to the page and needs `stickyHeader` true. ListGroup is the web twin of native's: a `ul` (role kept) of ListRows with hairlines between them, a `panel` or `plain` rows in a Card; `maxHeight` (`{ rows }` of a title and one detail line) scrolls the rows in the shared named scroll region with top and bottom shades, and `footer` is pinned under it outside the list (a ListRow there is a `div`). A ListRow with `onPress` or `href` is the whole button or link (named by title and value, described by its details, a chevron, an inset ring, 44 px on a coarse pointer); `selected` is a choice with a check; without either it is a statement; `leading` is a hidden consumer mark. BarChart is a labeled horizontal magnitude chart. DataBar is a decorative (`aria-hidden`) range bar for a table cell or list row, `from` to `to` on a `min` to `max` domain with a zero line when it spans zero; its tones (`neutral`, `success`, `muted`, `strong`, `accent`, `danger`) are semantic colours mixed into the surface; money out is `muted`, never danger, and `danger` is for a shortage only. ChartLegend is a chart's key: a list (`role="list"` kept) of items, each an `aria-hidden` swatch (`bar`, `line`, `marker`, `box`) and its words; a swatch reads its colour from a shared tone class (`sw-chart-tone-<tone>`, `src/css/chart-tones.ts`) whose custom properties (`--sw-chart-fill`, `--sw-chart-stroke`, `--sw-chart-ink`) every chart mark reads too, so a swatch is always the colour of the mark it names; a `bar` takes a fill tone (the categorical colours, DataBar's statement tones), the others a stroke tone (`accent`, `success`, `warning`, `danger`, `neutral`). DataBar's fills come from the same table. ColumnChart is columns per category (`stacked`, positives up and negatives down from zero, or `grouped`), series in categorical hues, an optional accent line on its own right-hand scale (zero and grid lines level with the columns', its last value beside that axis), a boxed `highlight` and `callouts` pinned above a column with a leader. It is an SVG laid out in its own pixels for the width it measures (`useChartWidth`; pure layout in `src/column-chart-*.ts`, scale and axis helpers shared with later charts in `src/chart-scale.ts`, `src/chart-axis.ts`, `src/chart-metrics.ts`); under `chartCompactWidth` it is shorter, labels fewer categories (always the last) and lists its callouts under the plot, never scrolling sideways. The drawing is `aria-hidden`; a table captioned by `label` in a `sw-sr-only` box (private `ChartTable`; a table is never narrower than its contents, so the box is what is hidden) carries every figure, the boxed row `aria-current`, and the callouts stay a list. LineChart is a value by date (`YYYY-MM-DD` points in date order, placed by days between them): `linear` or `step` (a value held until the next date), an optional `area` tint of its stroke tone, `markers` (a downward triangle and words on one of its points' dates, words dropped where they would meet), a boxed `highlight` period, labelled `ticks` (thinned from the last) and its last value beside the plot. It shares ColumnChart's measuring, scale, value axis, hidden table and plot CSS (`src/line-chart-*.ts`, `src/chart-dates.ts`, `css-line-chart.ts` for its area and markers). Pagination is a labelled `nav` holding the consumer's `rangeLabel` (a polite live region) and previous and next icon-only neutral Buttons named by `labels`; at an end a step is `aria-disabled`, never `disabled`, so it stays a Tab stop and focus is not dropped, and its press does nothing. Split is a start pane with a drag separator, a max width, and collapse below min. Accordion is a native `<details>` disclosure in page flow with a generated chevron in place of the browser triangle; `subtitle` is one muted line under the title and `size="sm"` is a nested disclosure with an `sm` control header. Dialog is a modal `<dialog>` on the top layer; `sheetBelow` docks it as a bottom sheet below the breakpoint, and `closeLabel` adds its own icon-only close button with a private CSS glyph (no icon dependency); `icon` and `description` fill the header, `footer` (with ActionBar's `summary` in a polite status) is pinned to its bottom edge, `size="xl"` is 65rem and `role="alertdialog"` marks a warning that interrupts. `appearance="banded"` (opt-in) is the solid sheet with its title row and footer as hairline-ruled bands and a round close button. StatTile is one figure with its label; `appearance="plain"` (opt-in) drops its surface, edge and padding for figures inside a card (never with `emphasis="primary"`), divided by a Separator the consumer composes. GlyphTile is a decorative categorical-colour square holding a white consumer glyph (a direct-child SVG is drawn at spacing step 4, the first slot that sizes its glyph) (the hues come from tokens; the consumer maps kinds to hues). Notice is a tinted note in the page's flow (info, success, warning, danger) that stays until the page removes it; its fill and ink come from the semantic colors, and danger is an alert; `variant="band"` is a full-width strip of page chrome (an environment strip) with no live region by default. Toast is an auto-dismiss status on the popover layer; it does not trap focus. `anchor` and `target` send it from a press to a destination; `placement="top-end"` with `title`, `action` and `showRemaining` makes it a corner card whose time holds on hover or focus. AppHeader is sticky glass chrome; `appearance="bar"` (opt-in) makes it a full-width band of the solid surface with a hairline under it and no rounding. `Tabs sticky` holds a page's section strip at the top as a band of the canvas on the AppHeader's layer, not a second header or a glass card. ActionMenu `triggerAppearance="text"` (opt-in) is an unframed trigger: its words and a chevron. ActionBar is a long page's actions and one polite live status line (optionally led by a `summary` figure: label, large tabular value, detail) on a glass bar stuck to the viewport bottom (optionally only below `md`), clearing the safe area; it is not a toolbar or a second header. Every generated `z-index` is a layer of `src/css/stacking.ts`; an open popup paints over the ActionBar. Stepper is a whole-number count between − and + (one spin button tab stop); `limitAppearance="plain"` keeps a button at its limit unfaded (still disabled). DenominationGrid entry rows are a strip's Steppers; a row's `valueRow` (opt-in, strip only) is a value line under it on the subtle fill, consumer-formatted values centred under the counts and the row's total moved onto it, each entry count described by its value; `labelAppearance="plain"` drops the row labels' tone stripe; `frame="table"`, `totalEmphasis="strong"`, `cellToneAppearance="pill"` and an empty `zeroLabel` are the opt-in framed count-sheet look (a frame on the scroll region, bold totals, a toned count on its tone's tint, blank zeros), off by default. Steps is a one-page vertical stepper; a Step only lives in a Steps list; `Steps open` (opt-in) keeps every step open as a region named by its title, its marker alone following the status, nothing `aria-current` and no focus moved. Nav is a label-size link cluster; a `Button` in it is a 44 px target on a coarse pointer; `appearance="words"` (opt-in) draws its destinations as plain words, the current one bold in the text color. `NavCount` is a count placed inside a destination after its words: SectionNav's count pill (one shared rule, `css-count-pill.ts`), read in the destination's name, `countLabel` in place of the bare number. SectionNav is the quieter navigation between one area's sections: links with `aria-current`, a row marked by an underline or, from `verticalFrom`, a side list marked by a bar; `onNavigate` takes a plain press for a client router. An item's `count` is a pill read in its name; `appearance="filled"` is the quiet button row beside an area's name. ThemeProvider `palette` applies a named token overlay; do not invent hex in JSX to retint the canvas. `ThemeProvider canvas="grouped"` (opt-in, `data-canvas`) is the page on a quiet grey under white cards (light: the background with 7 % muted; dark: the background), read from `--sw-canvas-grouped` by any surface that sits on it; links and accent words stay in the cards. Every press control and link renders an explicit `tabIndex` (`tabStop` in `src/tab-stop.ts`, a radio group's checked radio by `radioTabStopValue`), because Safari leaves buttons, links, checkboxes and radios out of the Tab order without one; a consumer's `tabIndex` wins and a deliberate `-1` (Stepper −/+, roving items) stays; every SegmentedControl item is a stop (its arrows change the value, not the focus). A new raw `<button>`, link or checkbox takes it too. Public names stay generic so every product can reuse them.
9. A new or changed public web token, class, variant, or component is not done until `apps/gallery` demonstrates the meaningful states.

## Prefer

```ts
<Box as="a" href="#layout" padding={4} paddingTop={2}>
  {children}
</Box>
```

which maps to `sw-padding-4 sw-padding-top-2`.

## Avoid

Hex colors in JSX, copied CSS in examples, and React Native primitives.
