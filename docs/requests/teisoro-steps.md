## Accepted API (2026-10-11)

`Steps` (props type `StepsProps`) is an ordered list (`ol`) of `Step`s (props type `StepProps`, status type `StepStatus`):

- `Steps`: `children` (the `Step`s, in order), `headingLevel?: 2 | 3 | 4` (default 2, each step's title heading), `labels?: Partial<StepsLabels>` (the words assistive technology hears for a status: `done`, `error`, `skipped`, `upcoming`; English by default), and the `ol`'s HTML attributes, such as `aria-label`.
- `Step`: `status`, `title`, `summary?` (one line beside the title, shown only when done, truncated with an ellipsis), `onEdit?` with `editLabel` (a ghost small `Button` at the end of a done step's line, named by its label and the step's title, such as "Edit The sale"), `skippedReason?` (muted words after a skipped step's title, such as "not needed"), `headingLevel?` (overrides the list's), and `children` (the step's fields, rendered only while the step is current or in error).
- Each step is a glass panel; steps are numbered by their order. The marker is the number in a ring (upcoming, skipped), the number on the accent (current), a check on the success color (done) or "!" on the danger color (error). A line joins each marker to the next, in the success color below a done step.
- The current step has `aria-current="step"`. A done, error, skipped or upcoming step's heading ends in its status word for assistive technology (visually hidden), except a skipped step with a visible reason.
- When a step becomes current from a folded state (upcoming, done, skipped), focus moves to its heading (a programmatic focus target, `tabindex="-1"`), so a keyboard or screen reader user lands on the step that opened; if several do in one update, the first in the list takes it. A step that renders current on first mount, moves between current and error, or turns to error does not take focus: after a refused submit the consumer focuses the first invalid field, as `Field` asks.
- Failure boundary: a `Step` outside `Steps`, a Fragment child of `Steps`, a blank `title`, an unknown `status` or `headingLevel`, `onEdit` without a nonblank `editLabel`, or a blank `skippedReason` throws a `RangeError`. Scalewing owns no copy beyond the default status words; Teisoro owns step titles, summaries, the Edit label, the order rules and what Edit reopens.

Sizes on Scalewing's scale (Teisoro D-2): the marker is the `xs` control height (28), an open step's title is the `title` variant (20/28, the board's 19), a folded step's title is body size at label weight (17, the board's 17), the summary is label size at regular weight (15). No new tokens.
