Scalewing request from Teisoro.

Status: released in `@scalewing/react` 1.29.0 (PR #129; Teisoro F-011-S04, release R3 "identity", item 13; the redesign inventory's row 16). The web counterpart of the native `MultiSelect` (`futmas-multi-select.md`); no code is shared (AGENTS.md rule 9).
Renderer: react
Missing surface: a web `MultiSelect`: several choices from a short list behind one trigger.
Why Box/Stack/Inline/Card/Text/Button/Field cannot do this: the F-011 Services day (ServicesDayLedger2, and VoidRows refers to it) filters the ledger with a "Show" menu: a trigger that names what is shown ("Show All entries"), a panel with All and Clear, one checkbox per service with its coloured tile, a hairline, and "Drawer movements". `Select` is one choice; `ActionMenu` runs commands; `FilterChips` is a row of chips in the page, not a compact trigger; a consumer composition of a Button and a positioned panel would need CSS and popover placement Scalewing owns.
Existing surface this might already be: `Select` (single value), `ActionMenu` (commands), `FilterChips` (single choice), the native `MultiSelect` (another renderer).
Workaround I almost used: `FilterChips` with every service, which takes a row of the page.
Teisoro use: the `CashLedger` composite's Show filter on the Services day, PosDay's change today and VaultToday.
Proposed API (inventory): `label`, `options: {value,label,icon?}[]`, `value: string[]`, `onChange`, `allLabel`, `clearLabel`, `summary` (trigger text). Each option shows a small GlyphTile, never a bare dot.

## Accepted API (2026-10-11)

- `MultiSelect` (props `MultiSelectProps`): `label` (the trigger's muted lead and the panel's name), `options: readonly MultiSelectOption[]` (`{ value, label, icon?, separatorBefore? }`; `separatorBefore` draws a hairline before an option, as the board's before Drawer movements), `value: readonly string[]`, `onChange(value: string[])` (the checked values in the options' order), `allLabel`, `clearLabel`, `summary` (the trigger's words after the label, written by the consumer), `disabled?`, `align?: 'start' | 'end'` (`MultiSelectAlign`).
- Pattern: a disclosure, not a listbox. The trigger is a `button` named by its words ("Show All entries") with `aria-expanded` and `aria-controls`; the panel is a `role="group"` named by `label`, with All and Clear (ghost `sm` Buttons) over one native checkbox per option (Checkbox's generated control), on the popover layer beside the trigger (as ActionMenu's list: under it, start-aligned or end-aligned, flipping to stay on screen). The first checkbox takes focus when it opens; ArrowDown on the trigger opens it; Escape (in the panel or on the trigger) closes it with focus on the trigger; disabling it while open closes it for good; focus or a press leaving it closes it. An option's `icon` is `aria-hidden`.
- Its panel is a popup in `css/stacking.ts` (a glass Card holding it lifts) and turns solid under reduced transparency.
- Failure boundary: a blank `label`, `summary`, `allLabel` or `clearLabel`, no options, an option without a value or label, a duplicate value, a `value` entry that is not an option, or an unknown `align` throws a `RangeError`.
- Sizes on Scalewing's scale (Teisoro D-2): the trigger is the `md` control (44; the board's 40), option rows are 44 (board 40), the Checkbox mark is 24 (board 18), the panel at least 16rem (`--sw-select-max`; the board's 260), the trigger's words are label type 15/600 with the label at 500 (board 14/600), a `space-2` (8) gap between label and summary (board 8), option rows label size 15 at body weight 400 (board 15/400), and the row hover tint is Select's 16% muted. The group is named by `label` ("Show"), where the board names it "Show these entries". All and Clear are ghost Buttons in the accent (the board's blue links).
- Generated classes `sw-multi-select`, `sw-multi-select-trigger`, `sw-multi-select-label`, `sw-multi-select-summary`, `sw-multi-select-panel`, `sw-multi-select-commands`, `sw-multi-select-row`, `sw-multi-select-row-separated`, `sw-multi-select-option`, `sw-multi-select-icon`, `sw-multi-select-text`.

Evidence: `multi-select.test.tsx` (the trigger's name and disclosure, focus on open, values in order, All and Clear, the hidden mark and the separated row, Escape returning focus, ArrowDown, focus leaving, disabled, failures, the generated rules and the popup layer); gallery "MultiSelect" (habitats with GlyphTiles and a separated "Station moves"); `apps/gallery/e2e/multi-select.spec.ts` on desktop-en, mobile-es and forced-colors (placement under the trigger, 44 rows, toggling, All, Clear, Escape, a press outside).
